# Hosting y operación

La solución puede vivir en un VPS dedicado/aislado o en Hermes Cloud. El repositorio no contiene credenciales ni decide por sí mismo el proveedor.

## Requisitos no negociables
- tenant/perfil independiente;
- memoria y almacenamiento separados;
- credenciales propias;
- backup y exportación verificables;
- responsable operativo identificado;
- política de acceso administrativo;
- procedimiento de recuperación y salida.

## Preguntas para Hermes Cloud
- ubicación y retención de datos;
- acceso administrativo del proveedor;
- exportación de memoria, skills y configuración;
- backups y recuperación;
- SLA y soporte;
- costos de infraestructura, créditos, modelos y herramientas;
- aislamiento entre clientes;
- migración posterior a VPS.
