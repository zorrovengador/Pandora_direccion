# Operación y soporte

## Rutina mínima
- revisar salud del gateway y proveedor;
- comprobar backups;
- revisar errores de conexión sin exponer contenido;
- mantener skills versionadas;
- registrar cambios de permisos;
- probar restauración periódicamente.

## Incidentes
1. Contener la acción o canal afectado.
2. No borrar evidencia.
3. Determinar si hubo acceso, exposición o solo fallo técnico.
4. Revocar credenciales comprometidas fuera del chat.
5. Informar alcance confirmado y acciones tomadas.
6. Documentar recuperación y prevención.

No confundir un error de proveedor con una brecha de seguridad sin evidencia.
