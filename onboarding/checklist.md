# Checklist de onboarding

## Antes
- [ ] Perfil Hermes independiente creado.
- [ ] Skills instaladas y visibles.
- [ ] Fuentes autorizadas identificadas.
- [ ] Modo solo lectura verificado.
- [ ] No hay credenciales, memoria ni sesiones compartidas.
- [ ] Tres demostraciones preparadas.
- [ ] Contacto operativo definido.

## Durante
- [ ] Explicar qué puede y no puede hacer.
- [ ] Calibrar tono, extensión e iniciativa.
- [ ] Probar briefing ejecutivo.
- [ ] Probar preparación de junta.
- [ ] Probar captura de acuerdos y pendientes.
- [ ] Confirmar fuentes y acciones que requieren aprobación.

## Después
- [ ] Registrar preferencias aprobadas.
- [ ] Registrar decisiones y pendientes.
- [ ] Acordar piloto y fecha de revisión.
- [ ] Verificar que no se guardaron secretos ni documentos innecesarios.
